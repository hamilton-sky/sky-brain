The current direction in six lines

One database

Postgres on Nanogres holds everything. No graph or vector database. Markdown is a view and an export, never the truth.

No server LLM

sky-brain never calls an LLM, except server-side embeddings. Agents run in the model each person connects.

Stewards and Workers

Stewards (Curator, Consolidator, Archivist, Auditor) keep the brain healthy. Workers (PO, Doer, Reviewer, your own) do the work. The Gatekeeper is plain server code.

Kind and trust level

Two fields (D22). Kind: fact, decision, hypothesis, observation with evidence, external. Trust: quarantined, proposed, approved. Only a person raises trust.

Grow entries

Extend the existing entries table and add versions, links, episodes, embeddings, uses and intentions.

pgvector is on

Zakai enabled pgvector 0.8.1 on the sky_brain database, so halfvec and HNSW are ready for step 4.
