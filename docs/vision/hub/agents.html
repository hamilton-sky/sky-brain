The first design for agents on the board: versioned role prompts served over MCP, workflow templates that stamp out tasks, and one task DAG that Claude and Codex both pull from.

Update note added to the doc today

  • sky-brain is now a shared memory plus board, not only a coordination board for coding agents.
  • Agents are two families: Stewards keep the brain, Workers do the work. Tester, builder and reviewer are Workers.
  • The context slice is now a context packet with "what we don't know" lines. Lessons go up through the trust levels, and only a person approves.
  • complete_task is now report_task with evidence. Claims, leases and the task DAG are live.

Its four diagrams were relabelled to match: Track instead of Feature, Trust instead of Status, packet instead of slice, claim_task and report_task.

What still holds

Versioned agent prompts

An agent is a named role prompt with a scope and a version. A task records the version it ran with, and only owners can edit them.

One graph

Agents are labels on tasks in the task DAG. They never call each other; the board's edges decide what is ready next.

Workflow templates

A saved graph of roles, such as feature-flow (tester, builder, reviewer), becomes real tasks when a feature starts.

Roles

Owner, Member and Viewer on a workspace. Sign-in stays invite-only through Perminister.
